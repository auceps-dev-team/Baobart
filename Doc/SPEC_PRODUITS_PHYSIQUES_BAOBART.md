**Toutes les œuvres de l'esprit créatif · livraison des produits physiques**
**Document N — v1.0 — août 2026**

> Complète le plan directeur (§2.3 types de produits, §3.10-F expédition physique) et la spec livraison numérique (`SPEC_LIVRAISON_PREVIEWS_ASSETS.md`). Deux questions : **(1)** quels produits sur Baobart (extension du numérique à toutes les œuvres de l'esprit : sculpture, peinture, artisanat…), **(2)** comment le client récupère les produits **physiques**.

---

## 1. Vision : Baobart, marché de toutes les œuvres de l'esprit

**Décision de positionnement** : Baobart couvre **toutes les œuvres de l'esprit créatif** — pas seulement le digital. Le fil conducteur reste le même : *du vrai matériel local, fait par des créateurs du continent, monétisé en FCFA.*

**Réalité honnête (ce qui guide la feuille de route)** :
- La **v1 est 100 % numérique** (flyers, affiches, mockups, fonts, packs…) : c'est ce qui prouve le marché, la communauté et le paiement mobile money **sans** la complexité logistique.
- Le **physique arrive en phase 2**, par ordre de risque croissant : **print-on-demand → seller-shipped (escrow) → hubs de confiance**.
- Le physique n'est **jamais** un simple ajout de type de produit : il déclenche un **sous-système complet** (livraison, escrow, retours, douane) — traité dans ce document.

```
shot/design numérique ──► option « décliner en produit physique »
                          ├─► Affiche imprimée (print-on-demand local)

```

C'est la **brique d'entrée** du physique : elle réutilise le catalogue numérique, sans stock ni logistique de l'artiste, et **valide la demande** avant d'investir dans les hubs.

## 3. Les 3 modèles de vente physique

### 3.1 Modèle A — Print-on-demand (recommandé pour commencer)

- L'artiste active « proposer en physique » sur un shot/design.
- Baobart (ou un partenaire imprimeur local) **imprime à la demande** : affiche, tirage, tote bag, carte postale.
- **Zéro stock**, **zéro logistique de l'artiste** : l'imprimeur produit et expédie (ou livre au hub).
- Prix = prix du design + **coût d'impression** + **livraison** (Baobart prend une marge sur l'impression — revenu additionnel).
- Déclinaison : **tirage numéroté** (ex. 50 exemplaires signés) → permet de monter le prix (rareté) avec un certificat.
- **Pourquoi en premier** : risque opérationnel minimal, valide la demande, réutilise l'existant.

### 3.2 Modèle B — Seller-shipped (l'artiste expédie)

- L'artiste liste un objet physique (sculpture, tableau, bijou…), définit **frais de livraison par pays/zone**, **délai de préparation**, et (option) **assurance**.
- **Paiement en escrow** : l'acheteur paie → Baobart **retient les fonds** → l'artiste expédie (avec **numéro de suivi**) → l'acheteur **confirme la réception** (ou photo) → **déblocage** des fonds à l'artiste (moins commission/frais).
- **Sécurité** : si pas de confirmation sous X jours après le suivi livré, déblocage auto ; litige possible (voir §7).
- **Pourquoi ensuite** : c'est le vrai marketplace physique — mais il exige l'escrow et la confirmation, sinon c'est la porte ouverte aux arnaques.

### 3.3 Modèle C — Hubs de confiance (à l'échelle)

- **Partenariats avec des hubs d'emballage/expédition** dans les grandes villes (Abidjan, Dakar, Lagos, Accra, Bamako) : ateliers, galeries, écoles d'art, coopératives.
- L'artiste **livre au hub** (proche de chez lui) → le hub **qualité-contrôle, emballe, expédie** (avec assurance) → suivi complet.
- Avantages : qualité d'emballage standardisée (œuvres fragiles), délais fiables, **regroupement de colis** (coût réduit), confiance renforcée (badge « Expédié par un hub Baobart »).
- **Pourquoi à l'échelle** : coûteux à mettre en place (partenariats, SLA) mais indispensable pour l'art fragile à volume.

## 4. Flux de commande physique (escrow) — le cœur

```
ACHAT PHYSIQUE
  1. Acheteur paie (mobile money / carte) → fonds en ESCROW (statut "hold")
  2. Notification artiste "prépare et expédie sous X jours"
  3. Artiste confirme l'expédition + NUMÉRO DE SUIVI (obligatoire)
     └─> statut commande "expédiée"
  4. Transporteur livre (coursier / hub / DHL)
  5a. Acheteur CONFIRME la réception (bouton)  → déblocage fonds → artiste payé
  5b. Auto-confirmation si suivi "livré" + délai (ex. 7 j) écoulé sans litige
  5c. Litige possible à tout moment avant confirmation (voir §7)
  6. Evaluation mutuelle (artiste/acheteur) — alimente les notes et badges
```

**Garanties Baobart** (protection des deux côtés) :
- **Acheteur protégé** : l'argent n'est libéré qu'à la réception confirmée (ou suivi livré).
- **Artiste protégé** : la preuve d'expédition (suivi) empêche les « je n'ai rien reçu » malhonnêtes ; l'auto-confirmation le paie sans dépendre de l'acheteur.
- **Fraude détectée** : numéro de suivi faux / jamais pris en charge par le transporteur → dossier ouvert, fonds non libérés.

## 5. Zones de livraison & tarifs

### 5.1 Découpage en zones

| Zone | Portée | Logistique typique |
|---|---|---|
| **Zone 0 — Retrait** | Même ville (Abidjan, Dakar…) | Retrait sur point relais / marché / atelier (gratuit ou ~1 000 F) |
| **Zone 1 — Nationale** | Même pays | Coursier national (Glovo, Jumia Logistics, colis express) — ~2 000-8 000 F |
| **Zone 2 — Régionale UEMOA** | CI, SN, BF, BJ, ML, TG, NE… | Transport régional + hub — ~5 000-20 000 F selon volume |
| **Zone 3 — Continent** | Reste de l'Afrique (NG, GH, KE, ZA…) | DHL / partenaires — ~15 000-60 000 F |
| **Zone 4 — International (diaspora)** | Europe, Amériques, Asie | DHL / Colissimo / Chronopost — ~25 000-150 000 F (selon poids/volume) |

### 5.2 Tarifs (paramétrables par artiste + barème Baobart)

- **Livraison calculée** : poids + dimensions + zone (pattern `shipping_destination` de Gumroad : taux 1 article / plusieurs articles).
- **Gratuité** : seuil « livraison offerte dès X FCFA d'achat » (option artiste).
- **Assurance optionnelle** : % du prix (recommandée pour peintures/sculptures — 1-3 %).
- **Aucun surcoût caché** : le total (prix + livraison + assurance + frais) est affiché **avant** paiement.

### 5.3 Le cas diaspora (point fort)

- Prix **localisé** (PPP §3.4) : l'acheteur à Paris voit le prix en €, le créateur reçoit en FCFA.
- **Douane gérée** par le transporteur international (DHL dédouane, droits à la charge de l'acheteur, affichés à l'avance autant que possible).
- **Emballage export** : hub ou artiste (bulles, caisse bois pour sculptures, tube pour toiles).

## 6. Emballage, certificat & provenance

| Œuvre | Emballage recommandé |
|---|---|
| Toile/tableau | **Tube rigide** (roulé) ou caisse bois (si non démontable) + calage |
| Sculpture (fragile) | Caisse bois sur mesure, mousse, « Fragile » visible |
| Bijoux | Boîte rigide, papier de soie, poche |
| Textile/wax | Plié + film, rouleau optionnel |
| Tirage/affiche (POD) | Tube en carton rigide |

- **Certificat d'authenticité** (œuvres uniques) : n° de série, artiste, technique, année, dimensions — généré par Baobart (réutilise le pattern certificat de licence §E) + **photo à la livraison** (preuve d'état).
- **Provenance** : pour les œuvres uniques, le certificat + le filigrane C2PA du shot source (si design numérique) lient le physique à sa version digitale.
- **Conseil d'emballage** : checklist intégrée dans le dashboard artiste (« prenez une photo avant envoi ») — réduit les litiges.

## 7. Retours, litiges & remboursements (physique)

| Cas | Règle |
|---|---|
| **Jamais livré** (suivi sans mouvement > 15 j) | Remboursement automatique + litige ouvert + signalement artiste |
| **Endommagé à l'arrivée** | Photo exigée sous 48 h → remboursement (ou remplacement) selon assurance |
| **Différent de l'annonce** | Litige → médiation → remboursement partiel/total (le certificat + photos servent de preuve) |
| **Article perdu en transit** | Suivi + assurance couvre ; Baobart rembourse l'acheteur, l'assurance indemnise |
| **Rétractation** (loi consommation, diaspora) | Fenêtre légale (14 j UE) sauf œuvres personnalisées (exclues par nature) |
| **Fraude artiste** (jamais envoyé, faux suivi) | Fonds non libérés, remboursement, **suspension** (risk state §3.8) |
| **Délai de préparation dépassé** | Notification + option annulation |

**Règles d'or** : preuves photo de chaque étape (artiste avant envoi, transporteur à livraison) ; délais de réponse litige ≤ 48 h ; historique des litiges par vendeur → seuil → statut de risque dégradé.

## 8. Données (modèle Prisma — complément blueprint)

```prisma
enum FulfillmentModel { DIGITAL PRINT_ON_DEMAND SELLER_SHIPPED HUB }

model Product {
  // ... blueprint existant ...
  fulfillment   FulfillmentModel @default(DIGITAL)
  weightGrams   Int?
  dimensions    String?          // "40x30x5 cm"
  fragile       Boolean @default(false)
  insurancePct  Decimal?         // option artiste
  shippingProfileId String?
  printOptions  Json?            // POD : [{format, price}] (ex. A3 5 000 F, tirage n° 12 000 F)
  editionSize   Int?             // tirages numérotés (ex. 50)
  editionNumber Int?             // réservé à la vente
  authenticityCertificateId String?
}

model ShippingZone {              // pattern Gumroad shipping_destination
  id          String @id @default(cuid())
  code        String  @unique     // Z0 | Z1 | Z2 | Z3 | Z4
  name        String              // "UEMOA"
  countries   String[]            // codes ISO
  baseRate    Int                 // FCFA
  perExtraKg  Int?
  isActive    Boolean @default(true)
}

model ShippingProfile {           // profil de livraison d'un artiste
  id          String @id @default(cuid())
  sellerId    String
  name        String
  prepDays    Int     @default(3) // délai de préparation
  rates       Json    @default("{}") // { zoneCode: { base, perKg } } ou zone par défaut
  freeShipThreshold Int?          // livraison offerte dès X FCFA
  carrier     String?             // coursier | hub | dhl | colissimo
}

model PhysicalOrder {             // commande physique + escrow
  id            String @id @default(cuid())
  orderItemId   String @unique
  sellerId      String
  buyerId       String
  zone          String            // Z0..Z4
  shippingRate  Int
  insurance     Int     @default(0)
  totalHeld     Int               // montant retenu en escrow
  status        String  @default("pending_prep") // pending_prep | ready | shipped | delivered | confirmed | disputed | refunded | completed
  trackingNumber String?
  carrier       String?
  packedAt      DateTime?
  shippedAt     DateTime?
  deliveredAt   DateTime?
  confirmedAt   DateTime?
  proofPhotoUrl String?           // preuve de livraison / état
  disputeRef    String?
  createdAt     DateTime @default(now())
}

model PrintJob {                   // print-on-demand
  id          String @id @default(cuid())
  productId   String
  printerId   String              // partenaire imprimeur
  format      String              // A3 | A2 | tirage | tote...
  quantity    Int
  status      String @default("queued") // queued | printing | shipped | done | failed
  price       Int
  createdAt   DateTime @default(now())
}
```

**Escrow (lien avec les soldes)** : le montant est créé en `BalanceTransaction` statut `on_hold` ; au `confirmedAt`, passage en statut payable → payout (§3.9-A). En cas de litige, statut `refunded`/`disputed`. (Réutilise le mécanisme de soldes existant.)

## 10. Feuille de route & impact

| Phase | Contenu physique | Modèle |
|---|---|---|
| **v1 (M1-M3)** | 100 % numérique (flyers, affiches, mockups, fonts, packs…) | — |
| **Phase 2a (M4-M5)** | **Print-on-demand** : affiches/tirages/tote bags depuis les shots | POD + hub imprimeur local |
| **Phase 2b (M6-M7)** | **Seller-shipped** : peintures, sculptures, artisanat, bijoux | Escrow + suivi + confirmation |
| **Phase 2c (M8+)** | **Hubs de confiance** dans les grandes villes | Hub + assurance + international |

**Décisions actées** :
- L'escrow + confirmation de réception sont **obligatoires** pour tout physique (sinon la fraude détruit la confiance).
- Le POD précède le seller-shipped (valide la demande sans risque).
- Le certificat d'authenticité + photos = la protection anti-litige.
- La diaspora est la cible privilégiée du physique (prix localisés, DHL, douane gérée).

**Revenus additionnels physique** (modèle économique A) : marge sur impression POD (10-20 %), frais de livraison (marge partielle), assurance (commission), commission 10 % inchangée sur le prix du produit.
